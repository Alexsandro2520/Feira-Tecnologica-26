# Como iniciar o projeto

## 1. Colocar o projeto no XAMPP

Copie a pasta do projeto para:

C:\xampp\htdocs\

Exemplo:

C:\xampp\htdocs\Feira-Tecnologica-26

---

## 2. Iniciar o XAMPP

Abra o XAMPP Control Panel e inicie:

- Apache
- MySQL

---

## 3. Importar o banco de dados

Abra:

http://localhost/phpmyadmin

Clique em **Importar**.

Selecione o arquivo:

feira_tecnologica.sql

Depois clique em **Importar**.

O banco utilizado pelo projeto é:

feira_tecnologica

As tabelas são:

- empresas
- usuarios
- posts
- likes
- comentarios

---

## 4. Abrir o projeto no VS Code

Abra a pasta do projeto no Visual Studio Code.

Depois abra:

**Terminal → Novo Terminal**

---

## 5. Entrar na pasta backend

No terminal do VS Code, execute:


cd backend# Como iniciar o projeto
